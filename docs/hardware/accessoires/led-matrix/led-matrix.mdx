# LED-Matrix

Die 12x8 LED-Matrix ermöglicht es, bunte Displays mit Neopixeln zu programmieren. So können LEDs individuell leuchten und Schriftzüge oder Motive in verschiedenen Farben dargestellt werden. Zudem lassen sich Informatik-Konzepte wie Arrays visualisieren.

<ImageWithText src={ledMatrix} alt="LED-Matrix" title="LED-Matrix" />{' '}

## Technische Informationen

- 12x8 Matrix
- 96 LEDs

                <h2>Bitmaps auf der LED-Matrix</h2>

                <p>
                Die LED-Matrix kann unter anderem Buchstaben und Zahlen anzeigen, aber auch
                selbst gestaltete <strong>Pixelgrafiken</strong>, sogenannte
                <strong>Bitmaps</strong>.
                </p>

                <p>
                Eine Bitmap besteht aus einem Raster von <strong>12x8 LEDs</strong> – jede LED
                kann einzeln auf verschiedene Arten angesteuert werden.
                </p>

                <h3>Was ist eine Bitmap?</h3>

                <p>
                Eine Bitmap ist im Grunde eine Tabelle, bei der jede Zelle (LED) eine Farbe
                bekommt. In Blockly kannst du diese als <strong>bunte Grafik</strong>
                darstellen, bei der jede LED eine eigene Farbe bekommt (RGB-Wert). Schwarze
                Zellen stellen ausgeschaltete LEDs dar. So kannst du viele verschiedene
                <strong>Pixelgrafiken</strong> erstellen und auf der LED-Matrix anzeigen
                lassen.
                </p>

                <img
                src="/img/hardware-bilder/led-matrix/happy_bitmap.svg"
                alt="Happy Bitmap"
                />

                <h3>Text anzeigen</h3>

                Buchstaben und Zahlen können auf der LED-Matrix angezeigt werden. Diese müssen
                nicht zwingend in der Bitmap-Form erstellt werden, sondern können in Blockly
                direkt mit dem entsprechenden Block definiert werden.
                </p>

                <img

                <h3>Emojis anzeigen</h3>

                <p>
                In Blockly gibt es einige voreingestellte Emojis, die auf der LED-Matrix
                angezeigt werden können. Dazu gehören z. B. ein Smiley, ein Hut oder ein
                Ritter. Um die Emojis anzuzeigen, musst du nur den entsprechenden Block in

                <h3>Weiteres</h3>

                <ul>
                <li>
                    <p>
                    Zusätzlich zur Erstellung von Bitmaps mit Hilfe des visuellen Blocks,
                    können erfahrene Nutzer auch jede einzelne LED ansteuern, indem die
                    <strong>RGB565 Farbwerte</strong> für jede einzelne LED definiert werden.
                    Dafür müssen in dem entsprechenden Block 96 RGB565 Farbwerte angegeben
                    werden, die die Farben der LEDs festlegen. Die LEDs werden von oben links
                    nach unten rechts angesteuert.
                    </p>

                    <blockquote>
                    💡 <strong>Tipp:</strong> Auf der folgenden{" "}
                    <a href="https://rgbcolorpicker.com/565">Website</a> ist es möglich, eine
                    Farbe auszuwählen und sich den RGB565 Farbwert ausgeben zu lassen.
                    </blockquote>

                    <img
                    src="/img/hardware-bilder/led-matrix/rgb565_block.svg"
                    alt="RGB565 Block"
                    />
                </li>

                <li>
                    <p>
                    Mit dem <code>Pixel setzen</code>-Block kannst du auch eigene Bitmaps
                    erstellen, indem du die einzelnen Pixel der LED-Matrix ansteuerst. Dazu
                    musst du die Koordinaten der Pixel angeben, die du ansteuern möchtest. Die
                    Koordinaten beginnen bei 0 und enden bei 11 für die x-Achse und bei 7 für
                    die y-Achse. So können einzelne Pixel der LED-Matrix mit wechselnden Farben
                    bespielt werden. Auf diese Art ist es möglich, kleinere Animationen zu
                    erstellen.
                    </p>

                    <blockquote>
                    💡 <strong>Tipp:</strong> Wenn du mehrere Pixel färbst, kann es zum
                    Flackern der LEDs kommen. Deaktiviere <code>Zeige sofort</code> bei allen
                    Blöcken und aktiviere es nur beim letzten Block in der Reihe. So wird alles
                    auf einmal angezeigt.
                    </blockquote>

                    <img
