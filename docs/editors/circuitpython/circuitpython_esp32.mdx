# CircuitPython installieren

Mit CircuitPython kannst du deine senseBox MCU-S2 ganz einfach mit der Programmiersprache Python programmieren.
In dieser Anleitung zeigen wir dir Schritt für Schritt, wie du CircuitPython auf deiner senseBox MCU-S2 installierst. Du benötigst dafür keine Programmierkenntnisse.

## Voraussetzungen

Für die Installation benötigst du:

- Eine **senseBox MCU-S2**
- Ein **USB-Kabel**, das Daten übertragen kann (nicht nur zum Laden)
- Einen **Computer** mit Internetverbindung
- Den Webbrowser **Google Chrome** oder **Microsoft Edge**

## Installation mit dem senseBox Flash-Tool

Mit dem **senseBox Flash-Tool** kannst du CircuitPython einfach und schnell auf deiner senseBox MCU-S2 installieren.

1. Öffne das [senseBox Flash-Tool](https://flash.sensebox.de/).
2. Wechsle zum Reiter `Upload`, klicke auf `Sketch auswählen` und wähle `CircuitPython` aus.
3. Verbinde deine senseBox MCU-S2 über ein USB-Kabel mit deinem Computer.
4. **Aktiviere den Bootloader-Modus:**
   - Halte den `BootSwitch`-Button gedrückt.
   - Halte `BootSwitch` weiterhin gedrückt und drücke gleichzeitig einmal kurz den Button `Reset`.
   - Lasse anschließend den `BootSwitch`-Button los.

6. Klicke auf `Sketch hochladen!`, um CircuitPython zu installieren. **Wichtig:** Trenne die senseBox während der Installation nicht vom Computer. Die Installation kann einige Minuten dauern.

7. Drücke nach Abschluss der Installation kurz den `Reset`-Button auf deiner senseBox MCU-S2.

8. Warte einige Sekunden. Deine senseBox sollte jetzt als neues USB-Laufwerk mit dem Namen CIRCUITPY auf deinem Computer erscheinen.
Du findest das Laufwerk unter Windows im Datei-Explorer oder unter macOS im Finder.

**Geschafft!**
CircuitPython ist jetzt auf deiner senseBox MCU-S2 installiert. Du kannst mit deinem ersten Python-Programm beginnen!
