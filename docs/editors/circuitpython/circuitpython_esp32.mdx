# CircuitPython installieren

Mit CircuitPython kannst du deine senseBox MCU-S2 ganz einfach mit der Programmiersprache Python programmieren.
In dieser Anleitung zeigen wir dir Schritt für Schritt, wie du CircuitPython auf deiner senseBox MCU-S2 installierst. Du benötigst dafür keine Programmierkenntnisse.

## Voraussetzungen

Für die Installation benötigst du:

- Eine **senseBox MCU-S2**
- Ein **USB-Kabel**, das Daten übertragen kann (nicht nur zum Laden)
- Einen **Computer** mit Internetverbindung
- Den Webbrowser **Google Chrome** oder **Microsoft Edge**
