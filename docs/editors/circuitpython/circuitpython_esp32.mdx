# CircuitPython installieren

CircuitPython ist eine Variante von MicroPython, die von Adafruit entwickelt wurde. Es ist eine vereinfachte Version von Python, speziell für Mikrocontroller. CircuitPython ist eine großartige Möglichkeit, um schnell und einfach mit der Programmierung von Mikrocontrollern zu beginnen. In diesem Tutorial zeigen wir dir, wie du CircuitPython auf deiner senseBox MCU-S2 installieren kannst.

![CircuitPython Logo](https://s3.amazonaws.com/adafruit-circuit-python/CircuitPython_Repo_header_logo.png)

<AlertBox type="info" title="Web-Browser!" >
    <p>Beide Installationsmethoden funktionieren nur mit Google Chrome oder Microsoft Edge.</p>
</AlertBox>

## Installation mit dem senseBox Flash-Tool

Mit dem **senseBox Flash-Tool** kannst du CircuitPython einfach und schnell auf deiner senseBox MCU-S2 installieren.

1. Öffne das [senseBox Flash-Tool](https://flash.sensebox.de/).
2. Wechsle zum Reiter `Upload`, klicke auf `Sketch auswählen` und wähle `CircuitPython` aus.
3. Verbinde deine senseBox MCU-S2 über ein USB-Kabel mit deinem Computer.
4. **Aktiviere den Bootloader-Modus:**
   - Halte den `BootSwitch`-Button gedrückt.
   - Drücke kurz den `Reset`-Button.
   - Lasse anschließend den `BootSwitch`-Button los.
<img src="/img/circuitpython/mcu-s2-bootloader-board-transparent.gif" width="680" alt="Bootloader-Modus aktivieren" />
5. Klicke auf `Board suchen`. Wähle im geöffneten Fenster das Gerät mit `ESP32-S2` im Namen aus und bestätige mit `Verbinden`.
<img src="/img/circuitpython/circuitpython_flash.png" alt="CircuitPython flashen" />
6. Klicke auf `Sketch hochladen!`, um CircuitPython zu installieren. **Die Installation kann einige Minuten dauern.**
7. Drücke nach Abschluss der Installation kurz den `Reset`-Button auf deiner senseBox MCU-S2.
8. Warte einige Sekunden, bis das Laufwerk `CIRCUITPY` auf deinem Computer erscheint.

**Fertig!** CircuitPython ist installiert. Du kannst jetzt mit der Programmierung deiner senseBox MCU-S2 beginnen.
