# Erste Schritte mit CircuitPython

CircuitPython ist installiert? Dann kannst du jetzt dein erstes Python-Programm auf deiner senseBox MCU-S2 schreiben!

In dieser Anleitung zeigen wir dir Schritt für Schritt, wie du deine senseBox mit dem CircuitPython Editor verbindest und dein erstes Programm ausführst.

## Voraussetzungen

Für dieses Tutorial benötigst du:

- Eine **senseBox MCU-S2** mit installiertem CircuitPython
- Ein **USB-Kabel**, das Daten übertragen kann
- Einen **Computer** mit Google Chrome oder Microsoft Edge

Falls du CircuitPython noch nicht installiert hast, folge zuerst unserer [Installationsanleitung](/docs/editors/circuitpython/circuitpython_esp32).

## Der CircuitPython Editor

Zum Programmieren verwenden wir den [CircuitPython Editor](https://code.circuitpython.org/).

Der Editor funktioniert direkt in deinem Browser. Du musst keine zusätzliche Software installieren.

### senseBox mit dem Editor verbinden

1. Verbinde deine senseBox MCU-S2 über ein USB-Kabel mit deinem Computer.
2. Öffne den [CircuitPython Editor](https://code.circuitpython.org/).
3. Klicke auf `Connect` und wähle die Verbindungsmethode `USB` aus.
4. Klicke auf `Connect to Device`.
5. Wähle im geöffneten Fenster deine `senseBox MCU-S2 ESP32S2` aus und bestätige mit `Verbinden`.


<div className="flex justify-center my-6">
    <img src={connect_senseBox_to_editor} alt="senseBox mit Editor verbinden" width="600" />
</div>


6. Klicke auf `Select New Folder` und wähle das Laufwerk `CIRCUITPY` aus.

   Das ist das Laufwerk deiner senseBox. Hier werden deine Python-Programme gespeichert.

7. Bestätige den Zugriff auf die Dateien, falls dein Browser danach fragt.
8. Klicke anschließend auf `Use CIRCUITPY`.

**Geschafft!** Deine senseBox ist jetzt mit dem Editor verbunden.

## Dein erstes Python-Programm

Jetzt schreiben wir ein kleines Programm, das den Text `Hello World!` ausgibt.

### Programm schreiben

1. Klicke im Editor auf `Open` und öffne die Datei `code.py`.

   Die Datei `code.py` enthält das Python-Programm, das deine senseBox ausführt.

2. Lösche den bisherigen Inhalt der Datei und füge folgenden Code ein:

   ```python
   print("Hello World!")
   ```

   Mit `print()` kannst du einen Text ausgeben. Der Text muss dabei in Anführungszeichen stehen.

### Programm ausführen

1. Öffne im Editor den Bereich `Serial`. Hier kannst du die Ausgaben deiner senseBox sehen.
2. Klicke auf `Save + Run`, um dein Programm zu speichern und auszuführen.

<div className="flex justify-center my-6">
    <img src={editor_save_and_run} alt="Save and run" width="850" />
</div>

Im Bereich `Serial` sollte jetzt der Text `Hello World!` erscheinen.

<div className="flex justify-center my-6">
    <img src={serial_monitor} alt="Ausgabe im seriellen Monitor" width="850" />
</div>

**Geschafft!**

Du hast gerade dein erstes Python-Programm auf deiner senseBox MCU-S2 ausgeführt!

### Probiere es selbst aus!

Ändere den Text in deinem Programm:

```python
print("Hallo senseBox!")
```

Klicke erneut auf `Save + Run`.

Jetzt sollte im Bereich `Serial` der Text `Hallo senseBox!` erscheinen.

Du kannst auch einen eigenen Text ausprobieren!

## Häufige Probleme

### Meine senseBox wird nicht gefunden

- Überprüfe, ob deine senseBox richtig mit dem Computer verbunden ist.
- Achte darauf, dass dein USB-Kabel Daten übertragen kann.
- Verwende Google Chrome oder Microsoft Edge.
- Versuche anschließend erneut, deine senseBox zu verbinden.

### Das Laufwerk CIRCUITPY wird nicht angezeigt

Überprüfe, ob CircuitPython auf deiner senseBox installiert ist.

Falls das Laufwerk weiterhin nicht erscheint, drücke kurz den `Reset`-Button auf deiner senseBox MCU-S2.

### Mein Programm zeigt keine Ausgabe

Überprüfe, ob du den Bereich `Serial` im Editor geöffnet hast.

Klicke anschließend erneut auf `Save + Run`.

Achte außerdem darauf, dass dein Programm genauso geschrieben ist wie im Beispiel.
